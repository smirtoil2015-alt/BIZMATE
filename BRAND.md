# BIZMATE Brand System

## Brand promise
**BIZMATE — The Intelligent Operating System for Business**

BIZMATE should feel like a calm, high-trust command center: intelligent, premium, precise and built for serious business decisions.

## Logo
Primary asset: `/public/logo.svg`.

The mark combines a geometric **B** with a connected-node network suggesting business identity, intelligence and a connected company. Use the horizontal lockup for public pages and the icon-only mark for app icons, favicon and compact navigation.

Never distort, stretch, redraw or place the mark over busy imagery.

## Typography
Primary typeface: **Inter**.

- 800–900: wordmark and display headings
- 700–800: buttons, KPI values and navigation emphasis
- 500–600: labels and important supporting text
- 400: body copy

Recommended fallback: `"Inter", "Segoe UI", system-ui, sans-serif`.

Arabic UI should preserve this hierarchy with a high-quality Arabic-capable system fallback or approved Arabic interface family.

## UI style
BIZMATE uses a **premium dark SaaS** visual language:

- generous whitespace
- 12–22px rounded surfaces
- subtle 1px borders
- restrained glass/blur only when it improves hierarchy
- minimal shadows; never heavy neumorphism
- high information density without clutter
- cyan/violet reserved primarily for intelligence and primary actions
- green/amber/red communicate state, not decoration

### Components
Primary buttons: brand gradient, dark text, bold weight.
Secondary buttons: dark/transparent surface, border, light text.
Inputs: dark surface, subtle border, visible focus ring.
Cards: layered surfaces with clear hierarchy.
Tables: compact but readable, strong column alignment.
Charts: neutral foundations with brand accents used for emphasis.

### AI surfaces
BIZMATE Intelligence uses the cyan → blue → violet spectrum with a subtle glow. AI recommendations must remain visually distinguishable from confirmed company facts.

### Status language
- Critical: red
- Warning: amber
- Healthy: green
- Informational / AI: cyan

## Layout
Desktop application shell:
- 240–260px sidebar
- 1px divider
- fluid content area
- 1180–1280px maximum width for public marketing sections
- 8px spacing rhythm

Responsive behavior:
- collapse the sidebar on small screens
- keep at least 16px page gutters
- stack multi-column cards below 900px
- maintain accessible touch targets

## Product voice
Clear, confident, practical and executive-friendly.

Prefer:
- “Needs attention”
- “Recommended next step”
- “Awaiting approval”
- “Business impact”
- “Why this matters”

Avoid hype inside the product. BIZMATE should demonstrate intelligence through useful context, evidence and actions.

## Core experience principle
**See → Understand → Decide → Act**

Every major BIZMATE screen should help the user progress through this sequence with minimal friction.
